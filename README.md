Customer Behavior Analysis

An end-to-end data analytics project exploring customer shopping behavior — from raw data cleaning to business insights to an interactive dashboard.

Pipeline: Python (data cleaning) → PostgreSQL / SQL (business analysis) → Power BI (dashboard & visualization)

 Project Overview

This project analyzes 3,900 customer transactions across four retail categories (Clothing, Accessories, Footwear, Outerwear) to understand what drives revenue, how customers respond to discounts and subscriptions, and where the biggest business opportunities lie.

The goal was to build a complete analytics workflow — not just a single chart — covering:

Data cleaning & feature engineering in Python
Business-question analysis using SQL (PostgreSQL)
Interactive dashboarding in Power BI

 Data Cleaning & Preparation

Key steps performed in the notebook before analysis:

Inspected data structure and summary statistics
Imputed missing Review Rating values using the median rating within each product category
Standardized column names (lowercase, underscores) and renamed purchase_amount_(usd) → purchase_amount
Engineered a new age_group feature (Young Adult, Adult, Middle Age, Senior) using quartile-based binning on age
Mapped frequency_of_purchases (e.g. Weekly, Fortnightly, Monthly) into a numeric field for easier analysis
Verified discount_applied and promo_code_used carried identical information (no conflicting data)
Loaded the cleaned dataset into PostgreSQL for SQL-based analysis

 Business Questions Answered (SQL)
What is the total revenue generated by male vs. female customers?
Which customers used a discount but still spent more than the average purchase amount?
Which are the top 5 products with the highest average review rating?
How do average purchase amounts compare between Standard and Express shipping?
Do subscribed customers spend more than non-subscribers?
Which 5 products have the highest percentage of discounted purchases?
How do customers segment into New, Returning, and Loyal based on purchase history?
What are the top 3 most purchased products within each category?
Are repeat buyers (5+ previous purchases) more likely to subscribe?
What is the revenue contribution of each age group?

Full SQL queries are available in queries.sql.

📊 Key Findings
Clothing dominates both revenue (~$104K) and unit sales (3.4M), more than double the next category (Accessories).
Gloves, Sandals, and Boots are the highest-rated products (avg. rating ~3.8+).
~50% of purchases in categories like Hats, Sneakers, and Coats involve a discount — yet 839 customers who used a discount still spent above the average purchase amount, showing discounts aren't only reaching bargain-hunters.
Subscribers don't spend more per order than non-subscribers ($59.49 vs. $59.87 average) — the subscription program isn't currently a spending lever.
72% of frequent repeat buyers (5+ purchases) are still non-subscribers, revealing a large untapped conversion opportunity.
The customer base is 80% "Loyal" (10+ purchases) but only 2% "New", highlighting strong retention but weak new-customer acquisition.
Revenue is evenly spread across age groups, meaning the product range appeals broadly rather than skewing to one generation.
